# Predict Simulator

Browser port of the Predict mobile UXR prototype. Predictions and account flows are simulated.

## Run locally

```bash
python3 server.py
```

Then open [http://localhost:4173/predict-simulator/](http://localhost:4173/predict-simulator/).

The phone frame loads the Expo web export at `/predict-simulator/app/`.

## Notes

This repo hosts the production web export (HTML, JS bundle, and images). It is not the original Expo/React Native source tree.
